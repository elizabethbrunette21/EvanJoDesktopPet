# Evan 连续动作版

当前桌面显示统一缩小至原来的 80%：站立高度约 168px，透明窗口 208×256px，交互区域和气泡一并适配。2026-11-17 根据用户纠正，移除额外脚底，只动原有两条圆头短腿。原生位移的小数补偿按实际显示缩放换算。

已补入视频中的敲锣和骷髅头杆子，当前为 17 种状态、37 个图集单元，详见 `prop-actions.md`。以下 15 种为第一批动作记录。

沿用认可的 v2 角色比例和扁平画法。所有运行中的立绘无嘴、无唇、无笑眼。实心红色竖椭圆眼为常态，闭眼只用于短暂眨眼、睡觉和伸懒腰。用户明确禁止的嘴巴和眯眼笑脸不得再次添加。

## 动作与素材

第一批包含待机、眨眼、左右看、歪头、认真听着、挥手、走路、坐下、睡觉、伸懒腰、跳起、悬浮、拖起、转身、举牌；随后补入敲锣与骷髅头杆子，共 17 种状态。现存六张源图共 37 个单元；原 8 帧走路图保留作历史素材。当前走路使用 `idle-v2.png` 中原有的圆短腿，不使用额外脚掌。

素材由内置 imagegen 参考 `idle-v2.png` 制作，位于 `assets/characters/evan/motion-v1/`。最终表情图为 `expressions-mouthless.png`；被否决的带嘴版本不用于应用。源 PNG 原样保留；旧生成素材里多出的脚底／脚尖通过运行时遮罩去除，待机与相应站立、道具姿势一起处理。

四段视频每段抽样 24 帧作为动作目录参考，可辨认站立、闭眼、举牌、悬空等变化。走路、坐卧及拖起等桌宠动作是补绘；本版不是对录屏所有动作的逐帧无损复刻。部分细小衣纹在生成的不同帧间仍有差异。

## 连续性

共享 Canvas 渲染器按屏幕刷新节奏绘制。v3 网格拉伸、v4 独立脚底都已被用户否决，不再使用。敲锣和持杆原视频可确认：两条浅色圆短肢是腿，中央黑色花纹部分是垂下的衣片，不能当作两条腿。

当前从原图中按轮廓提取两条完整短腿及其原有描边，移除身体里重复的可见腿区域，再各绘制一次完整小腿。没有脚掌、脚趾、鞋底或脚部关节图层。腿段仅在原来的上端支点作约 ±1.4° 摆动和不超过 0.3 逻辑像素的抬落；不缩放、不剪切。身体和中央衣片最后绘制，覆盖腿根。走路也不做纵向呼吸拉伸或转向时横向压扁。

两侧现有红绿花纹翅片的下方可见扇缘已加入微动，待机与走动时约 3.6 秒一轮、最大约 ±0.69°。只提取原图中被露出的翅尖，保留上缘根部、头发和串珠作为前景；不新增翅膀、不拉伸轮廓。翅尖先于原腿和身体绘制，暂停时与同一动画时钟一起冻结，系统减弱动态效果下保持静态。

脚步相位由实际行走距离驱动，每移动 20px 完成一次小步循环。走路与其他姿势之间不叠加两张脸；其他部分姿势仍使用约 120ms 的短过渡。敲锣保留直接关键帧击打。

启动短暂站立约 1.2 秒后开始行走，每次行走约 10.4 秒。活动仍洗牌轮换，但各项活动之间会继续走动，不再长时间在原地展示姿势。睡觉仍有轻微呼吸，醒来后继续活动。拖起时悬空摇摆，放下后回到活动。走路维持原版 Q 人的圆短腿画法，不添加完整人体脚部结构。

画面与窗口移动统一由渲染帧驱动，同一时刻最多一个移动请求。主进程只接受当前窗口的有限时间步长，保留系统 API 隔离。自动行走最高每秒 30 个逻辑像素，起步和停下逐渐加减速；原生窗口坐标取整后，用画布小数偏移补偿，避免每走一个像素都顿一下。边缘先刹停，约 0.48 秒后换朝向再走；转向不会把小人压扁。

可以把小人拖到桌面任意位置；放下后从该位置继续横向走动。跨屏移动由用户拖动，自动行走留在当前屏幕。屏幕改变只纠正位置，不主动显示隐藏的小人。

## 控制

右键或系统托盘：选择具体动作、切换自由走动、暂停动画、休息、隐藏和退出。关闭自由走动时仍播放原地动作。休息会进入睡姿；取消休息后伸懒腰继续。隐藏或暂停会停止动画时钟和自动行走；暂停保留当前画布，避免中途跳回站姿。拖动、休息、关闭走动会立即停止位移并作废旧请求，避免回跳或卡在半转身状态。遵循系统减弱动态效果设置，开启时保持静态。

两端使用同一套动作和素材，系统窗口 API 均留在主进程。为在操作其他应用时保持连续动画，窗口关闭 Electron 后台动画节流；隐藏时由程序主动停止绘制和移动。

## 验证

`npm test` 验证图集索引、动作轮换、拖起状态、暂停恢复、休息醒来、不同刷新频率下的加减速、边缘转向、完整小腿连续性与每腿仅绘制一次。`npm run smoke` 除实际窗口交互外，还直接读取素材像素，检查额外脚底已透明、两条原腿仍完整。

`npm run smoke -- --record-roaming` 导出 30fps 桌面走动预览帧（临时目录 `evan-roaming-preview/`）。当前预览为 `output/evan-chibi-legs-v5.mp4` 和同名 GIF；v3/v4 保留作被否决的历史版本。预览背景用于展示实际位移；桌宠本身仍是透明窗口。

`npm run smoke -- --record-wings` 导出 30fps 的单轮待机翅尖微动，预览为 `output/evan-wing-sway-v6.mp4` 与 GIF。走动、腿型与缩小后的尺寸继续沿用当前版本。

`npm run smoke -- --record-preview` 在系统临时目录 `evan-motion-preview/` 导出连续 PNG 帧，供预览编码使用。测试截图在临时目录 `evan-motion-smoke/`。

## 生成提示约束

三个图集均以 `idle-v2.png` 为身份参考：保持短身、红色豆豆眼、两点红蛾眉、遮脸长发、黑灰衣纹、黑红绿袖纹、金领饰和青色串珠；简单平涂，粗深色线，不加立体光照。图集分别要求 4×2 走路八个连续相位、4×2 待机与眼部变化、4×3 坐卧及其他活动。每格完整人物、统一头部尺寸、透明间隔、无文字。

最终无嘴修正的完整提示词见 `motion-mouthless-prompt.txt`。未采用的带嘴版本已从运行素材中移出。
