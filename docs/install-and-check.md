# 安装与双端验收

## macOS

打开 `dist/` 中的 DMG，把 Evan 拖到“应用程序”，然后启动。也可以解压 Mac ZIP 后打开 Evan.app。通用包包含 Apple Silicon 和 Intel 两种架构。

目前是未签名测试版。如果 macOS 拦截启动，可在“系统设置 → 隐私与安全性”中对这次启动选择“仍要打开”。

## Windows x64

- 安装版：打开 `dist/` 中的 `Evan Setup 0.1.0.exe`，按向导选择安装目录。
- 免安装版：把 `Evan-0.1.0-win.zip` 完整解压到一个文件夹，再打开里面的 `Evan.exe`。不要只从 ZIP 中单独取出 EXE，旁边的资源文件需要一起保留。

目前 Windows 包未配置代码签名。Mac 上成功生成 Windows 包，只能确认打包完成；Windows 的运行结果须在 Windows 环境另行记录。

## 使用

点击小人会回应，按住拖动可换位置，右键可以选择动作。菜单栏／系统托盘中的两点红眉图标可找回隐藏的小人。

“自由走动”和“暂停动画”会在重启后保留。休息、隐藏及临时动作只在本次运行生效。想结束程序时，从托盘菜单选择“退出 Evan”。

## 两端实机检查

每个系统分别记录系统版本、显示缩放及通过／未通过结果：

- 启动后透明显示，大小合适，托盘图标可操作；再次启动能找回已有的小人。
- 红眼、长发、两枚分开的红蛾眉保持一致，无嘴。只有原有两条圆短腿，翅尖轻动。
- 在屏幕上连续走动，到边缘减速转向；拖动后能从新位置继续走动。
- 暂停后画面和位置不变；关闭“自由走动”后停在原地。
- 退出并重新打开，位置、走动和暂停设置恢复。
- 点击、拖动、17 种动作、休息及隐藏／显示均可正常使用。
- 在副屏和不同缩放下拖动后仍可操作；拔掉副屏后小人回到可见区域。

自动检查：在对应系统、Node.js 24 环境中执行 `npm ci`、`npm test`、`npm run smoke`。打包后执行 `npm run smoke:packaged`。GitHub Actions 会分别在 macOS 和 Windows 中完成这些步骤，检查通过后上传安装包。
