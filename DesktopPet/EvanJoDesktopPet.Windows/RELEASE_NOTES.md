## Windows x64 preview

Download `EvanJoDesktopPet-Windows-x64.zip`, extract it, and double-click `Install.cmd`. The self-contained app installs for the current user, creates an **Evan Jo Desktop Pet** desktop shortcut, and opens the pet. Quit the running pet before installing an update. Windows 10 or later is required; no separate .NET installation is needed. This preview is unsigned, so Windows may show a publisher warning.

## Windows x64 预览版

下载并解压 `EvanJoDesktopPet-Windows-x64.zip`，双击 `Install.cmd`。程序会安装到当前用户目录、创建 **Evan Jo Desktop Pet** 桌面快捷方式并打开宠物。更新前请先退出正在运行的宠物。需要 Windows 10 或更高版本，无需另装 .NET。本预览版尚未签名，Windows 可能显示发布者警告。
